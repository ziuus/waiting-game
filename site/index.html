Why Waiting Game

Built for the in-between moments

Waiting for a build, a deploy, or a meeting to start? That's game time.

🪟

Transparent Overlay

Full-screen, no chrome. The game renders on top of your desktop — your workspace stays visible underneath.

⚡

Near-Zero Idle Cost

When hidden, the game uses negligible CPU and RAM. No impact on your work when you don't need it.

⌨️

Instant Toggle

Hide with a keypress. Bind a global hotkey in your compositor and the game is always a keystroke away.

📊

Global Leaderboards

Every score submits to a live leaderboard. Track your rank across all players, in every game mode.

🎮

Six Game Modes

Dino Runner, Flappy Bird, Gravity Runner, Cyber Snake, Neon Breakout, and Defender — each with unique physics.

🎨

Customizable

Enable, disable, rename, and theme every game through the config file. Full control over your roster.

Get Started

Download & Install

Available for Linux, macOS, and Windows. Pick your platform below.

Recommended

AppImage

Download and run — no dependencies required.

curl -L -o waiting-game.AppImage \
https://github.com/ziuus/waiting-game/releases/download/v0.4.2/waiting-game_0.4.2_amd64.AppImage
chmod +x waiting-game.AppImage
./waiting-game.AppImage

Toggle Binding (Hyprland)

Add this to your hyprland.conf for quick toggle:

bind = SUPER SHIFT, G, exec, pkill waiting-game \|\| ~/Applications/waiting-game-0.4.2.AppImage

DMG Installer

Intel & Apple Silicon supported. Download from releases.

# Download waiting-game_0.4.2.dmg from
# https://github.com/ziuus/waiting-game/releases/latest
# Open the DMG and drag to Applications

Installer

Windows .exe / .msi installer available.

# Download the .exe or .msi from
# https://github.com/ziuus/waiting-game/releases/latest

⚙️ Configuration

The game reads ~/.config/waiting-game/config.json (auto-created with defaults). 

{
  "activeGame": "dino",
  "activeDifficulty": "normal",
  "games": {
    "dino": { "enabled": true },
    "flappy": { "enabled": true },
    "gravity": { "enabled": true },
    "snake": { "enabled": true },
    "breakout": { "enabled": true },
    "defender": { "enabled": true }
  }
}
